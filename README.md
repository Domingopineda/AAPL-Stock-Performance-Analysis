# 📊 Apple Stock Performance Analysis (1980–2025)

## 📌 Project Overview
This project analyzes Apple’s historical stock performance using financial market data from 1980 to 2025. The analysis focuses on identifying long-term trends, stock volatility, daily price movements, and market activity patterns.

The project was built using SQL, Tableau, and Excel to simulate a real-world financial data analytics workflow.

---

## 🎯 Business Questions

1. How has Apple’s stock price grown over time?
2. How volatile is Apple’s stock?
3. How strong are Apple’s daily price movements?
4. Do moving averages help identify trends?

---

## 🛠️ Tools Used

- SQL → Data analysis and calculations
- Tableau → Data visualization and dashboard creation
- Excel → Data review and preparation

---

## 📈 Key Insights

### 📌 Stock Growth
Apple’s stock price has shown strong long-term growth, especially after 2017. The company reached a closing price near 237 in 2025, demonstrating consistent market expansion.

### 📌 Volatility
Apple’s stock maintains relatively low volatility, indicating stable price behavior compared to highly volatile assets.

### 📌 Daily Price Movement
Daily price movements remain moderate overall, with occasional spikes during periods of increased market activity.

### 📌 Moving Averages
Moving averages help identify long-term trends and major market shifts by smoothing short-term price fluctuations.
